Foundational Overview

Project Objectives & Purpose

Primary Objective

To design, synthesize, and experimentally validate an integer-native (INT8) hardware accelerator for Transformer Self-Attention on an edge FPGA (Cyclone IV), eliminating floating-point units and multi-cycle LUT dequantization stages in Softmax.

Why is this project necessary?

  • • Hardware Constraint on Edge Silicon: Low-cost FPGAs (Cyclone IV) have zero native floating-point DSP units. Standard Softmax relies on real-valued exponentials ex.
  • • Softmax is the Critical Bottleneck: While matrix multiplications (Q, K, V) are readily accelerated by MAC arrays, Softmax accounts for over 33% of inference cycles due to non-linear exponentiation and division.
  • • Local Edge Privacy: Classifying voice commands directly on-chip prevents privacy exposure and eliminates cloud round-trip latency.
Application Target: Real-time Smart Home Spoken Intent Classification (6 classes, L=8, D=32).

Theoretical Rationale

Why Propose Tier 0 and Tier 1?

Version A (Baseline)

Conventional Detour

Dequantizes INT8 scores to fixed-point, queries a 256-word exponential ROM, accumulates, and requantizes back to INT8.

• Softmax Cycles: 2,008
• ROM Overhead: 256 words
• Mean Abs Error: 0.100967
Slow, memory-heavy, interpolation errors.
Tier 0 (Proposed)

Integer-Native Shift Only

Transforms ez into 223z/16. Evaluates exponentials purely via hardware barrel shifting. Zero lookup tables.

• Softmax Cycles: 1,880 (-128)
• ROM Overhead: ZERO ROM
• Mean Abs Error: 0.002312
Ideal for ultra-constrained area budgets.
Tier 1 (Proposed)

Shift + 16-LUT Refinement

Decomposes into 2-q × 2-f/16. Integer shift handles coarse scale; a tiny 16-word table handles fractions.

• Softmax Cycles: 1,880 (-128)
• ROM Overhead: Only 16 words
• Mean Abs Error: 0.000246 (400x lower)
Maximum precision with zero latency penalty.

Honest Engineering Appraisal

Engineering Trade-offs & Limitations

1. Precision vs. Memory Footprint (Tier 0 vs Tier 1)

• Tier 0 has 0-word memory cost but slightly higher MAE (0.0023) due to dropping fractional terms.
• Tier 1 spends a minimal 16 words of ROM to drop MAE by 10x to 0.000246 with identical 1,880-cycle latency.

Conclusion: Tier 1 is optimal whenever 16 words of block memory are available.

2. Fixed Tensor Dimensions (L=8, D=32)

• Fixed sequence length guarantees strictly deterministic 5,560-cycle inference with zero memory management unit (MMU) overhead.
• Limitation: Longer sentences must be truncated or processed in 8-token sliding windows.

Conclusion: Perfectly suited for short embedded voice command spotting.

3. Sequential Restoring Division vs. Area

• The 24-bit bit-serial restoring divider takes 24 cycles per token × 8 = 192 cycles/row.
• A fully parallel array divider would complete in 1 cycle but would consume ~4,000 extra Logic Elements.

Conclusion: Sequential division was chosen to keep total LE utilization under 20%.

4. On-Chip ROM vs. Dynamic Model Weight Loading

• Baking weights into Verilog synthesis ROMs eliminates external SDRAM controllers and bus latency.
• Changing model weights requires updating Verilog ROMs and recompiling the FPGA bitstream.

Conclusion: Ideal for dedicated embedded appliance controllers.

Faculty Defense Q&A: Mathematical Core

Q1: “Why did you choose 23/16 specifically for log2(e)?”

Answer: In base-2 Softmax, log2(e) ≈ 1.442695. In fixed-point digital hardware with a 4-bit fraction (Q4.4), the closest power-of-two fraction is 23/16 = 1.4375 (only 0.36% relative error). Dividing by 16 is free in Verilog—it is simply taking bits [7:4] as quotient and [3:0] as fraction without any divider logic.

Q2: “How does Tier 1 achieve 400x lower error than Version A without adding extra clock cycles?”

Answer: Version A quantizes the entire [-8, 0] exponent range across 256 entries. Tier 1 decomposes 2-q × 2-f/16. The coarse decay 2-q is computed exactly by a barrel shift, while the 16-entry LUT only needs to resolve the small interval [0, 1). The 16-word lookup happens in parallel with the shift, incurring 0 extra cycles.

Q3: “What is the purpose of subtracting the maximum value (z = x - max(x))?”

Answer: This is Safe Softmax. Calculating ex on positive numbers causes rapid integer register overflow. By setting z = x - max(x), all z ≤ 0, which guarantees ez ∈ (0, 1]. This guarantees intermediate sums fit safely within 16-bit accumulators.

Faculty Defense Q&A: Hardware Architecture

Q4: “Why use a 24-bit restoring divider instead of Verilog's behavioral division operator (/)?”

Answer: The behavioral division operator (/) synthesizes into a massive combinational path that creates long routing delays and destroys the clock frequency. Our sequential 24-bit restoring divider shifts and subtracts 1 bit per cycle, guaranteeing clean 50 MHz operation with minimal Logic Element usage.

Q5: “Why does every command take exactly 5,560 clock cycles?”

Answer: Our pipeline is strictly deterministic. Dimensions are fixed (L=8, D=32), there are no cache misses or dynamic while-loops, and the restoring divider executes exactly 24 iterations per token. This zero-jitter execution is critical for hard real-time edge embedded systems.

Q6: “How much FPGA silicon does your accelerator consume?”

Answer: In Quartus Prime compilation, the entire top-level design consumes only 20,635 Logic Elements (18%) and 8 Embedded 9-bit Multipliers (2%) out of 114,480 LEs available on the EP4CE115 FPGA, proving it is highly viable for low-cost edge deployment.
