Introduction & Background

Problem Statement

The Challenge: Transformers on Edge FPGAs

  • • Transformers achieve state-of-the-art accuracy in NLP and speech intent classification tasks
  • • Standard Softmax requires floating-point exponentials — NOT natively supported on Cyclone IV FPGA
  • •
    Conventional workaround = Fixed-Point Detour:
    INT8 Scores → Descale → 256-entry Exp LUT → Sum → Divide → Requantize → INT8 Output
This detour introduces:
• Extra latency (+16 cyc/row)
• Heavy memory (256-ROM)
• Multipliers for scaling
Research Question

"Can integer-native Softmax eliminate the fixed-point detour on a Cyclone IV FPGA, achieving lower latency while preserving 100% accuracy?"

Comparative Architectural Analysis

3 Softmax Architectures Compared

Version A Conventional Baseline

Conventional Fixed-Point Detour

  1. 1. Find Max (8 cycles)
  2. 2. Descale: z = S - max (8 cycles)
  3. 3. Exp LUT: 256-entry ROM (8 cycles)
  4. 4. Restoring Divider x8 (192 cycles)
  5. 5. Requantize to INT8 (8 cycles)
Softmax Cycles: 2,008
Total Cycles: 5,688
Latency @50MHz: 113.76 μs
• 256-entry exponential ROM
• Descale + Requant stages
• Extra pipeline overhead
Tier 0 Proposed

Integer-Native Base-2 Shift Only

  1. 1. Find Max (8 cycles)
  2. 2. Shift amount: t = (-z) × 23
  3. 3. Barrel shift: w = 32768 >> t
  4.    (No Exp ROM needed!)
  5. 4. Restoring Divider x8 (192 cycles)
Softmax Cycles: 1,880 (-128)
Total Cycles: 5,560
Latency @50MHz: 111.20 μs
• ZERO exponential ROM
• ZERO descale / requant stages
• Pure barrel shifter logic
Tier 1 Proposed

Base-2 Shift + 16-Entry LUT

  1. 1. Find Max (8 cycles)
  2. 2. Q4.4 decompose: q = t>>4, f = t&F
  3. 3. LUT[f]: reads 16-entry frac table
  4.    w = LUT[f] >> q
  5. 4. Restoring Divider x8 (192 cycles)
Softmax Cycles: 1,880 (-128)
Total Cycles: 5,560
Latency @50MHz: 111.20 μs
• Only 16-word fractional LUT
• No descale / requant stages
• Highest numerical precision
